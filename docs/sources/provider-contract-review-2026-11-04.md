# Provider contract review: November 4, 2026

The October 20 review exceeded the fourteen-day cadence on November 3, so `npm run check:provider-contracts` failed on every branch, and the daily monitor had opened one issue per drifted page (#108, #110, #111, #112, #115, #116, #117) plus the cadence issue (#118). All fourteen registered pages and one newly registered page were fetched and reviewed before the registry date and fingerprints were refreshed. Baselines for the review came from Wayback Machine copies normalized the same way as the checker: for the Terra, Luna, Anthropic pricing, Anthropic Enterprise analytics and Gemini pricing pages a copy hashed exactly to the pinned content, and for every other page a copy reproduced the pinned semantic fingerprint, so the diffs below are against the reviewed state and not guesses.

## Changes supported by the review

- [Gemini Developer API pricing](https://aistudio.google.com/docs/pricing.md) moved. `https://ai.google.dev/gemini-api/docs/pricing` now redirects to `aistudio.google.com/docs/pricing`, whose HTML is a JavaScript shell with no text, which is why every reviewed marker went missing (#115). The Markdown mirror at `/docs/pricing.md`, listed in the site's `llms.txt`, is now the monitored page, and `aistudio.google.com` is an approved host. Gemini 2.5 Pro keeps its published rates ($1.25 / $10 / $0.125 per million tokens up to 200k-token prompts; $2.50 / $15 / $0.25 above), but the page now states that the model is deprecated and that from December 1, 2026 every request to `gemini-2.5-pro` routes to Gemini 3.8 Flash and is billed at 3.8 Flash rates ($0.75 / $3.75 / $0.075 through December 31, 2026; $1.50 / $7.50 / $0.15 from January 1, 2027). The registry records that claim and pins the 3.8 Flash rates; the estimator change is a separate pull request. Gemini 4 Argon rates and their December 1 change are unchanged. The Vertex AI pricing page was considered and rejected: it is a different product and carries no deprecation notice.
- `normalizeDocument` now strips only tag-like sequences (a tag name, closing slash, comment or processing instruction after `<`). The Markdown mirror writes `prompts <= 200k tokens` with a bare `<`, which the previous rule swallowed through the next `>`, together with the price above 200k tokens. Every reviewed HTML page normalizes identically under both rules, so no HTML fingerprint moved because of this change.
- [Anthropic Usage and Cost API](https://platform.claude.com/docs/en/manage-claude/usage-cost-api) (#111): the implemented `usage_report/messages` and `cost_report` endpoints are now documented as a legacy API that remains supported, with no sunset date. The recommended successor is the beta [Usage and Cost Analytics API](https://platform.claude.com/docs/en/manage-claude/usage-cost-analytics-api) (`GET /v1/organizations/analytics/usage` and `/cost`, header `anthropic-beta: analytics-usage-cost-2026-08-24`, six-decimal cent strings with `list_amount`, roughly four-hour freshness). Examples switched to `anthropic-version: 2026-10-21`, whose published changes do not touch the implemented endpoints; the connector keeps sending 2023-06-01. On Claude Models on Google Cloud (Anthropic managed) only the usage endpoint is reachable. The registry records all of this, declares the two Analytics endpoints as targets, and monitors the Analytics guide. No connector behavior changed.
- [Claude Enterprise Analytics](https://platform.claude.com/docs/en/manage-claude/analytics-api) (#112): the four `/v1/organizations/analytics/` cost and usage report endpoints are legacy and remain supported; the other Enterprise Analytics endpoints are not. Organizations with customer-managed encryption keys can see zero `lines_of_code` and `commit_count`, under-counted `pull_request_count`, and uncounted slash-command skills. Under API version 2026-10-21 the per-user reports rename `actor.email` to `actor.email_address` and `summaries` to `data`. Enterprise remains contract-only and untested.
- [Cursor models and pricing](https://cursor.com/docs/models-and-pricing) (#108): the Cursor Token Rate ($0.25 per million tokens on Teams and Enterprise) now applies only to eligible third-party models, explicitly to input, output and cached tokens; third-party models whose cache-read price is below $0.10 per million tokens across every tier are exempt, BYOK included, as are Cursor models and Cost mode. Regional data residency adds a 10% uplift. The registry's pricing context says so. The connector reports `spendCents` as-is and never repriced Cursor usage, so nothing changed there.
- [GitHub Copilot usage-based billing](https://docs.github.com/en/copilot/concepts/billing/usage-based-billing-for-organizations-and-enterprises) (#116): restructured on October 28. AI credits are the unit for metered Copilot usage in organizations and enterprises; Copilot Business and Enterprise seats contribute pooled included credits (1,900 and 3,900 per user per month, unchanged), while the Copilot access plan has no included allowance and is metered from the first credit. One AI credit is still $0.01 USD. The connector reads gross, discount and net amounts per SKU and did not change; the registry notes that a Copilot access organization can show zero included-credit discount.
- [OpenAI organization usage and costs reference](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage) (#110, P0): the only change inside any reviewed claim is that integer fields are now typed `integer` instead of `number`; that was established by reproducing the pinned fingerprint from the live page with that single reversal, and confirmed against the public OpenAPI specification, which already carried `api_source`, both cache-write retention fields, `user_id` on the costs result and the Decisions usage endpoint on October 20. The connector already requires integers and knows every documented field. Six markers were added so the fields it consumes are reviewed claims.
